# GitHub Capacity Cascade Platform

A production-minded SRE / Platform Engineering project that builds an ephemeral developer platform on Azure AKS and evaluates its reliability using a failure class derived from GitHub's public August 2026 capacity incident.

> Status: project foundation and architecture contract are being established.

This repository is intentionally separate from `github-capacity-cascade-lab`: the Lab is the research foundation; this repository is the engineering and operations case study.
